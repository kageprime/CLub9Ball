# 九号俱乐部 CLUB No.9

像素风 · 第一人称 · 真物理的 3D 台球网页游戏。纯静态、无构建步骤：Three.js + Rapier 通过 import map 引入。

## 运行

```bash
npm install          # 只为跑测试（Rapier）；游戏本身走 CDN
npm test             # 61 个用例；装了 Rapier 后物理/骰盅的 10 个用例会从“跳过”变成真跑
node serve.mjs                  # 零依赖静态服务器，然后打开 http://localhost:8000
# Windows：直接双击 start.bat（会自动开服务器并打开浏览器）
# 也可用 python3 -m http.server 8000。⚠ 不能双击 index.html（file:// 下浏览器禁止加载 ES 模块）
```

## 对局模式（开始画面 / 暂停菜单里切换）

| 模式 | 说明 |
|---|---|
| 人机对战 | 你 对 电脑；难度 简单 / 普通 / 高手（误差、看走眼概率、思考时间不同）。你犯规，电脑自由球；电脑犯规，你自由球 |
| 双人对战 | 同屏轮流击球 |
| 练习 | 自由练球，不判规则 |
| 观战 | 电脑 对 电脑（触屏设备自动进入） |

链接参数：`?mode=cpu|twop|practice|watch`，`?spectate=1` 等同观战。终局会弹出结算（进球 / 出杆 / 犯规 / 最长连击）和“再来一局”。

## 镜头

`1` 自动 · `2` 球后 · `3` 俯视 · `4` 转播 · `5` 侧拍（贴台边低机位）· `6` 环绕 · `7` 追球；`C` / `Shift+C` 循环。环绕：方向键转动 / 俯仰，`[` `]` 推拉（按方向键会自动切到环绕）。
“自动”：自己瞄准用球后，电脑回合与球滚动用转播机位。进球特写仍会临时接管镜头。机位逻辑在 `src/cameras.js`。

## 骰子扑克（酒吧骰桌，走近按 Q）

五颗骰、最多三投（首投 + 两次重投），和庄家比牌型：五条 > 四条 > 葫芦 > 顺子 > 三条 > 两对 > 一对 > 散牌。`↑/↓` 下注，空格发牌 / 重投，`1–5` 留骰，回车收手摊牌，`H` 牌型表。你的骰子是真物理抛出的；庄家的骰子藏在骰盅里摇、再揭开。赢牌按牌型加奖金（顺子 / 葫芦 ×2，四条 ×3，五条 ×5）。逻辑在 `src/dice.js`，流程与界面在 `src/pokerdice.js`。

## 结构

```
index.html        import map + HUD / 面板 DOM
style.css         像素风 UI
src/
  table.js        桌面与球的常量（57.2 mm 球、台面、袋口）
  sim.js          物理核心（Rapier，不依赖 DOM；物理是唯一事实源）
  rules.js        简化中式八球 + 练习（纯逻辑）
  ai.js           观战 / 陪练 AI（纯几何）
  replay.js       每杆录制与回放（60 Hz 快照，只读）
  darts.js        标准镖盘、弹道求解器、三镖一轮、180
  bar.js          轮盘、筹码（旧的骰盅 DiceWorld 仍保留，供测试）
  dice.js         骰子扑克：牌型 / 比牌 / 庄家策略 + 托盘物理（Rapier）
  pokerdice.js    骰子扑克流程与界面
  cameras.js      七种镜头机位
  world.js        渲染（只读快照）：低分辨率渲染目标 + 抖动/调色板量化 → 最近邻放大
  textures.js     Canvas 程序化纹理（mulberry32 确定性）
  audio.js        采样 + 程序化混响 IR + 压限 + BGM
  i18n.js         中/英字典
  main.js         输入、状态机、HUD、小游戏、主循环
test/             physics / darts / bar / misc 四组 Node 测试
assets/           可选素材与说明（见 assets/README.md）
```

## 已知局限

- **渲染层与物理层在写入时没有在浏览器 / Rapier 里实际运行过**（开发环境无法访问 npm / CDN）。已通过语法检查、导入导出核对与 61 个 Node 用例（纯逻辑部分），物理手感（摩擦、恢复系数、杆速、袋口几何）需要你本地试打后调参，常量都在 `src/table.js` 的 `MAT` / `PHYS`。
- 球房 GLB 的“隐藏自带球桌”靠节点/材质名正则匹配（`pool|billiard|snooker`），不同模型命名不同，必要时在 `assets/config.json` 里指定。
- 测试 `直线正碰…定杆` 在改动前就已失败：半力一杆打出去，目标球只滚了约 9 厘米，说明台呢滚动阻力 / 杆速偏大或偏小，需要在 `src/table.js` 的 `MAT` / `PHYS` 里调手感。
- 一个“只有一颗子弹”的轮盘：下注/兑现按公平赔率，不是真钱。
